# Home Assistant Add-on: DSS VoIP Notifier

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

Make VoIP calls from Home Assistant and play a TTS message or an audio file
to whoever answers.

- Redials until someone answers (configurable ring time and retry timeout)
- Repeats the message a configurable number of times
- Several calls at the same time
- Works with any Home Assistant TTS integration

See [DOCS.md](DOCS.md) for configuration and usage.
